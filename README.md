# StockFlow — LEONI

Application Streamlit de réconciliation des stocks.

## Déploiement
- Fichier principal : `app.py`
- Dépendances : `requirements.txt`
- Sur GitHub, remplacez le fichier `app.py` existant par cette version corrigée.
- Streamlit Community Cloud redéploiera l'application après le commit.

Important : ne publiez pas de données réelles ou confidentielles de l'entreprise dans ce dépôt public.
